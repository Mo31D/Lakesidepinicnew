# Lakeside Picnic: technical SEO audit and repair, 14 October 2026

## Scope and evidence

GitHub main baseline: `20e24fb0809e031b4c024be25cca73e327e407fb`.
Source-driven TypeScript/React static build, 180 records, 179 public products,
198 generated HTML pages. No design, product identity, price, availability,
body description or product photograph is changed by this repair.

Reviewed the two Google Search Console notices dated 26 September 2026:
all five reported issues were **non-critical**. Merchant notices: missing global
identifier/brand, `hasMerchantReturnPolicy`, `shippingDetails`. Product notices:
missing `review`, `aggregateRating`. These are not evidence of an indexing ban.

## Root causes and permanent changes

| Finding | Cause | Source correction |
|---|---|---|
| Wrong local coordinates | Hard-coded town-centre location instead of the owner's GBP pin | Shared `businessLocation`: 54.4209, -2.9624; exact GBP Maps CID |
| In-store products described as ordinary InStock offers | Schema generator did not encode the purchase channel | Use `InStoreOnly` for available items; retain OutOfStock for unavailable items |
| 39 packaged drinks/snacks without brands | Original catalogue left supplier empty; supplier was also used as brand | Explicit brand field from exact product names; do not use “Prepared at Lakeside Picnic” as a brand |
| Two incomplete Google Product nodes | “Ask in store” records have no verified price or genuine product reviews | Do not emit Product rich-result nodes for these records; pages and catalogue remain indexable and unchanged |
| Product canonical/sitemap URLs redirect | Folder URLs omitted the terminal slash required by GitHub Pages | Normalize central productURL helper and route resolver; preserve all generated filenames and corrected product identities |
| Eleven overlong product meta descriptions | Full detailed product descriptions were reused as snippets | Separate concise `seoDescription`; retain the full visible product descriptions |
| Low CTR for Thunder & Lightning and Double Jersey | Search snippets could communicate maker, flavour and local price more clearly | Refresh those two descriptions using the current single-scoop price |
| 2 MB shop photograph downloaded at mobile sizes | One 4032px source was sent to every viewport | 640/960/1600px WebP derivatives of the existing served photograph, srcset/sizes, retained original |

Known brand labels are based on existing exact catalogue identities. No GTIN,
fake MPN, product rating, review, price-expiry date, shipping or return policy
has been invented. Unidentified/unbranded souvenirs remain unlabelled.

Product/Offer markup is retained for real, priced, in-store products. Google
supports InStoreOnly for product snippets. This does **not** guarantee removal
of Merchant Listing warnings: Google can still detect Offers in that report.
Online shipping/return warnings are not fixed with imaginary policies. Genuine
shop reviews must not be reused as ratings for individual products.

## Checks and observations

- HTTP and HTTPS / www and non-www resolve to the existing canonical HTTPS www host.
- robots.txt and sitemap.xml return HTTP 200; important pages are crawlable.
- Random missing paths and the obsolete combined tea-tray route return real 404s.
- Canonical legacy aliases already point to their intended current pages; duplicate titles on these aliases are intentional, not independent competing pages.
- TypeScript, static build, all-page manifest/link/schema checks, selection business rules and package verification are required before publication.
- Existing image-dimension registry was checked against actual assets: no mismatch.
- All 180 product records are compared against baseline to preserve existing facts and images.
- Initial Google Rich Results Test on Thunder & Lightning: five valid items, no critical error, optional warnings.
- Initial Google PageSpeed mobile: Performance 96, Accessibility 100, Best Practices 100, SEO 100; LCP 2.3s, CLS 0, TBT 0ms. This is a lab run, not a field CWV pass. CrUX returned “No Data”.
- PageSpeed identified the shop photo as approximately 1,948 KiB. Other small product images still have responsive-delivery opportunities; no broad image-library replacement is performed.
- PageSpeed API returned 429, so the supported PageSpeed browser interface was used instead.

## Google account and local-profile observations

Connected GSC performance property: `sc-domain:lakesidepicnic.co.uk`, owner
permission. Effective data range: 14 September–11 October 2026; comparison:
17 August–13 September. The connector provides performance, not Coverage,
URL Inspection or Validate Fix controls. The cloud-browser Search Console
session is not signed in. Do not claim validation or indexing submission.

Thunder page: 714 impressions, 1 click, CTR 0.14%, average position 9.59.
Double Jersey page: 117 impressions, no clicks, average position 9.26.
The tool flags possible Thunder/category cannibalisation, but the category has
only one impression for that query versus 371 on the flavour page; this is
insufficient evidence to merge or remove either page.

The authorised GBP read confirms name, phone, postcode and address. Primary
category is Ice cream shop, with Souvenir Shop and Tea and coffee shop secondary
categories. The profile is CLOSED_TEMPORARILY. Its description still mentions
Lakes Sandwiches, while sandwiches are unavailable in the catalogue. Regular
hours list only Tuesday, Saturday and Sunday. These facts should be reviewed
by the owner when reopening; no hours, closure status or profile text was changed.

## Remaining actions and opportunities

1. Owner: sign in to Search Console, inspect representative canonical URLs and sitemap, and request validation only for genuinely corrected issues. Allow Google to recrawl before evaluating reports.
2. Owner: verify the reopening schedule and remove unavailable sandwich wording from the GBP description; retain accurate closure status until reopening.
3. Supply exact brands/GTINs and the two missing prices where known; never manufacture identifiers or prices.
4. Measure Thunder/Double Jersey CTR after recrawl over comparable seasonal periods; avoid interpreting a closed-season decline as proof of a technical fault.
5. Further responsive variants for large product photos can reduce payload, but should preserve the existing image library. GitHub Pages controls the currently short cache lifetimes; changing hosting is outside this repair.
6. Genuine product reviews and an online shipping/returns policy are not prerequisites to invent for an in-store catalogue.
